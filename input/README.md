# Input folders

Topics are entered in `topics.txt` as `BOOK_ID|Topic`.

Large production assets are intentionally kept out of GitHub:
- Covers: Google Drive `INPUT_ASSETS/covers/{BOOK_ID}.png`
- Music: Google Drive `INPUT_ASSETS/music/`
- Video library: Google Drive `VIDEO_LIBRARY/<person-folder>/`

The repository folders remain as placeholders so the expected structure is obvious.
